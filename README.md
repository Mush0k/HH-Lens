# HH-Lens
HH-Lens - универсальная аналитичекая платформа для мониторинга рынка труда. Автоматический сбор данных, детекция манипуляций в вакансиях и живые дашборды для любой профессиональной области

Проект спроектирован как **универсальный движок**: начав с глубокой аналитики IT-сектора, система легко масштабируется на любую отрасль - от медицины и логистики до ритейла и госслужбы.

### Ключевые возможности
* **Универсальный парсинг:** Поиск и анализ вакансий в любом регионе и любой профобласти через гибкую систему фильтров.
* **Детектор манипуляций:** *Fake-Junior:* Выявление скрытых требований (опыт 3+ года) в вакансиях "без опыта".
    * *Salary-Bait:* Отсеивание нереалистичных зарплатных вилок.
* **Живая статистика:** Динамические дашборды, которые обновляются в реальном времени, а не раз в год.
* **Исторические данные:** Сохранение снимков рынка в PostgreSQL для отслеживания трендов (растет ли спрос на навык или падает).

### Стек технологий
- **Core:** Python 3.10+
- **Validation:** Pydantic (строгий контроль качества входящих данных)
- **Processing:** Pandas (аналитическая обработка массивов)
- **Database:** PostgreSQL (архивация и аналитика)
- **Interface:** Streamlit (интерактивная визуализация)
- **DevOps:** Docker (для стабильного деплоя)

### Структура проекта (Архитектура "Универсал")
* **hh-lens/**
    * 📂 **src/** — Ядро системы
        * `app.py` — Точка входа, интерфейс Streamlit.
        *  `parser.py` — Универсальный загрузчик данных из API.
        *  `models.py` — Pydantic-схемы (описание сущности "Вакансия").
        *  `processor.py` — Аналитический движок и фильтры.
        *  `database.py` — Модуль взаимодействия с БД.
    * 📂 **configs/** — Настройки для разных отраслей (IT, медицина, продажи и т.д.).
    * 📂 **data/** — Локальное хранилище для кэша и тестов.
    *  `requirements.txt` — Список зависимостей.
    *  `Dockerfile` — Инструкция для контейнеризации.
    *  `README.md` — Описание и план работ.
